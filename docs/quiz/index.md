# 📝 Quiz de clase

Al final de cada cátedra el profesor abre un **quiz de 20 minutos** con preguntas sobre lo que se vio en
la clase. Ingresa con la **misma cuenta de la Práctica** (correo USM, nombre y contraseña), presiona
*Comenzar* y responde antes de que se acabe el tiempo. Tienes **un solo intento**; la pauta se publica
cuando el profesor cierra el quiz.
